# Tangl Connector

Навык (skill) для Claude: чтение BIM-моделей из облачной платформы
[Tangl](https://tangl.cloud) обычным языком. Найти модель и версию, посчитать
элементы и объёмы, проверить параметры, сравнить версии, получить ссылку на
модель.

Только чтение. Изменить модель через коннектор нельзя.

- Установка и примеры – [USER_GUIDE.md](USER_GUIDE.md)
- Готовый архив навыка – [Releases](../../releases) и папка `releases/`
- Изменения – [CHANGELOG.md](CHANGELOG.md)

## Инструменты

| Инструмент | Что делает |
|---|---|
| `status` | проверка сети, входа и доступных компаний |
| `login` | сохранение данных для входа из `tangl.env` |
| `find_models` | поиск модели и версии |
| `model_schema` | категории, уровни, параметры и их заполнение |
| `query` | SQL-запросы к элементам версии, сравнение двух версий |
| `model_link` | ссылка на модель во вьювере Tangl |

## Требования

Платный тариф Claude с выполнением кода и доступом к доменам
`auth.tangl.cloud`, `platform.tangl.cloud`. Python 3.10+, `requests`, `duckdb`.
