# Tangl Connector – руководство пользователя

**Версия:** v1.0.0 · 2026-10-01

Tangl Connector – навык (skill) для Claude, который читает BIM-модели из
облачной платформы [Tangl](https://tangl.cloud). Вы задаёте вопрос обычным
языком, Claude находит модель, считает и проверяет данные и отвечает
таблицей, отчётом или файлом Excel.

Коннектор **только читает**: запросы на изменение, загрузку и удаление
блокируются до отправки в Tangl. Под каждым ответом Claude указывает модель,
версию и поле, по которому считал.

## Что нужно

1. **Платный тариф Claude** (Pro, Max, Team или Enterprise). Навыку нужно
   выполнять код и ходить в интернет к адресам Tangl, а добавить свои
   адреса в разрешённые на бесплатном тарифе нельзя.
2. **Учётная запись Tangl** с доступом к моделям.

## Установка

### 1. Персональный токен Tangl

1. В Tangl откройте раздел **«Персональные токены»** и нажмите
   **«Создать токен»**.
2. Название – например, `Claude`. Срок действия – на ваше усмотрение
   (можно без ограничений).
3. Скопируйте токен: он показывается один раз.
4. Создайте текстовый файл `tangl.env` с одной строкой:

```
TANGL_TOKEN=скопированный токен
```

Токен даёт доступ ко всем моделям, которые видит ваша учётная запись.
Когда срок истечёт, Tangl удалит токен – создайте новый и замените строку в
файле. Отозвать токен можно в том же разделе в любой момент.

Если у вас несколько компаний в Tangl, а работать нужно с одной, добавьте
строку `TANGL_COMPANY_ID=…`. Без неё поиск идёт по всем компаниям.

**Другой способ: клиент API с логином и паролем.** В Tangl создайте клиента API (раздел «Новый API»). Сервисы Value и Control
включать не нужно. Затем запишите в `tangl.env`:

```
TANGL_CLIENT_ID=id клиента API
TANGL_CLIENT_SECRET=секрет клиента API
TANGL_USERNAME=логин Tangl
TANGL_PASSWORD=пароль Tangl
```

### 2. Настройки Claude

В [claude.ai](https://claude.ai) откройте **Settings → Capabilities**:

1. Включите **Code execution and file creation**.
2. Включите **Allow network egress** и добавьте домены:
   - `auth.tangl.cloud`
   - `platform.tangl.cloud`

В Team и Enterprise эти настройки меняет владелец организации:
**Organization settings → Capabilities**.

### 3. Навык

1. Скачайте `tangl-connector-skill-vX.Y.Z.zip` со
   [страницы последнего релиза](../../releases/latest).
2. **Settings → Capabilities → Skills → Upload skill**, выберите архив.
3. Убедитесь, что навык **tangl-connector** включён.

### 4. Проект

1. Создайте проект в Claude, например «Tangl».
2. Добавьте `tangl.env` в файлы проекта.
3. Все разговоры о моделях ведите внутри этого проекта.

Файл можно не класть в проект, а приложить к первому сообщению в чате.
Claude сохранит данные для входа на время разговора.

### Проверка

Напишите в проекте: *«Проверь подключение к Tangl»*. Claude ответит, что
подключение работает, и покажет список ваших компаний.

## Примеры

**Найти модель**
> Найди в Tangl модели по объекту «Жилой комплекс, корпус 2». Какие версии
> есть и какая последняя?

**Разобраться в незнакомой модели**
> Что есть в модели КР корпуса 2? Какие категории, сколько элементов, какие
> параметры заполнены?

**Посчитать объёмы**
> Сколько бетона в стенах и перекрытиях по этажам и по маркам? Выгрузи в
> Excel.

Марка (класс) бетона берётся из названия материала, например
«Бетон В25 W6 F150» → В25.

**Проверить заполнение параметров**
> У каких элементов не заполнен код классификатора? Сгруппируй по
> категориям и типам.

**Найти несоответствия**
> Найди стены, у которых в имени типа «200 мм», а фактическая толщина
> другая.

**Сравнить версии**
> Что изменилось между 3-й и 4-й версиями модели АР? Сколько элементов
> добавлено, удалено и изменено, в каких категориях?

Сравнение надёжно для моделей из Revit. У моделей из IFC номера элементов
могут меняться между выгрузками, и Claude об этом предупредит.

**Быстрая справка**
> Сколько в модели противопожарных дверей EI60 и на каких этажах?

**Спецификация**
> Выгрузи в Excel все окна: тип, размеры, этаж, количество.

**Посмотреть модель**
> Дай ссылку на модель, хочу посмотреть проблемные элементы.

Ссылка открывает модель во вьювере Tangl, если вы вошли в Tangl в
браузере. Выделение по ссылке не передаётся, поэтому Claude даёт ещё и
список ID элементов.

## Если что-то не работает

| Сообщение | Что сделать |
|---|---|
| Нет выхода в сеть к auth.tangl.cloud | Добавьте домены Tangl в настройках (шаг 2) |
| Нет данных для входа | Добавьте `tangl.env` в проект или приложите к чату |
| Токен не принят | Срок токена истёк или он удалён – создайте новый (шаг 1) |
| Неверный логин или пароль | Проверьте `TANGL_USERNAME` и `TANGL_PASSWORD` |
| Неверные Client ID / Secret | Проверьте данные клиента API в Tangl |
| Модель не найдена | Проверьте, что у вашей учётной записи есть доступ к модели |
| Модель слишком большая | В версии больше 200 000 элементов. Спросите по модели отдельного раздела или секции |

## Что и где хранится

Коннектор работает во временной среде выполнения кода Claude. Она своя у
каждого разговора и удаляется вместе с ним. Внутри неё, в папке
`~/.tangl-connector`, лежат:

| Файл | Что это |
|---|---|
| `credentials.env` | данные для входа, если Claude сохранил их из `tangl.env` |
| `cache/elements_*.parquet`, `cache/materials_*.parquet` | выгруженные элементы и материалы открытых версий |
| `cache/versions_*.json` | список моделей и версий для подписи ответов |
| `cache/token_*.json` | временный токен (только при входе по логину и паролю) |

Очистить: попросите Claude *«Очисти данные Tangl»* – удалятся выгруженные
модели. *«Очисти всё, включая данные для входа»* – удалится и
`credentials.env`. Файл `tangl.env` в проекте Claude при этом остаётся,
удалите его в настройках проекта сами.

## Безопасность

- **Коннектор только читает.** Любой запрос на изменение, загрузку или
  удаление блокируется в коде коннектора до отправки в Tangl. Сам токен при
  этом даёт те же права, что и ваша учётная запись, поэтому храните его как
  пароль и ставьте срок действия.
- **Данные идут в Claude, как любой ваш вопрос.** Ответы Tangl – таблицы,
  имена, параметры – попадают в разговор с Claude. Коннектор
  обращается только к `auth.tangl.cloud` и `platform.tangl.cloud`, других
  адресов в коде нет.
- **Каждая цифра – со ссылкой на модель и версию.** Под таблицами Claude
  пишет источник: модель, версию и поле, по которому считал.
- Не публикуйте `tangl.env`, не кладите его в общие проекты и не
  пересылайте другим людям.

## Другие ИИ-ассистенты

Коннектор рассчитан на Claude. В обычном чате ChatGPT код не выходит в
интернет, поэтому подключиться к Tangl оттуда нельзя.
