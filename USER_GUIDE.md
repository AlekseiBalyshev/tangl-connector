# Tangl Connector – руководство пользователя

**Версия:** v0.1.0 · 2026-09-30

Tangl Connector – навык (skill) для Claude, который читает BIM-модели из
облачной платформы [Tangl](https://tangl.cloud). Вы задаёте вопрос обычным
языком, Claude находит модель, считает и проверяет данные и отвечает
таблицей, отчётом или файлом Excel.

Коннектор работает **только на чтение**: изменить, загрузить или удалить
модель через него нельзя.

## Что нужно

1. **Платный тариф Claude** (Pro, Max, Team или Enterprise). Навыку нужно
   выполнять код и ходить в интернет к адресам Tangl, а добавить свои
   адреса в разрешённые на бесплатном тарифе нельзя.
2. **Учётная запись Tangl** с доступом к моделям.
3. **Данные для API Tangl**: Client ID и Client Secret. Их выдаёт личный
   кабинет Tangl.

## Установка

### 1. Файл с данными для входа

Создайте текстовый файл `tangl.env`:

```
TANGL_CLIENT_ID=ваш client id
TANGL_CLIENT_SECRET=ваш client secret
TANGL_USERNAME=логин Tangl
TANGL_PASSWORD=пароль Tangl
```

Если у вас есть персональный токен Tangl, достаточно одной строки
`TANGL_TOKEN=…`.

Если у вас несколько компаний в Tangl, а работать нужно с одной, добавьте
`TANGL_COMPANY_ID=…`. Без этой строки поиск идёт по всем компаниям.

### 2. Настройки Claude

В [claude.ai](https://claude.ai) откройте **Settings → Capabilities**:

1. Включите **Code execution and file creation**.
2. Включите **Allow network egress** и добавьте домены:
   - `auth.tangl.cloud`
   - `platform.tangl.cloud`

В Team и Enterprise эти настройки меняет владелец организации:
**Organization settings → Capabilities**.

### 3. Навык

1. Скачайте `tangl-connector-skill-vX.Y.Z.zip` из раздела
   [Releases](../../releases) или папки `releases/`.
2. **Settings → Capabilities → Skills → Upload skill**, выберите архив.
3. Убедитесь, что навык **tangl-connector** включён.

### 4. Проект

1. Создайте проект в Claude, например «Tangl».
2. Добавьте `tangl.env` в файлы проекта.
3. Все разговоры о моделях ведите внутри этого проекта.

Файл можно не класть в проект, а приложить к первому сообщению в чате.
Claude сохранит данные для входа на время разговора.

### Проверка

Напишите в проекте: *«Проверь подключение к Tangl»*. Claude ответит, что
подключение работает, и покажет список ваших компаний.

## Примеры

**Найти модель**
> Найди в Tangl модели по объекту «Жилой комплекс, корпус 2». Какие версии
> есть и какая последняя?

**Разобраться в незнакомой модели**
> Что есть в модели КР корпуса 2? Какие категории, сколько элементов, какие
> параметры заполнены?

**Посчитать объёмы**
> Сколько бетона в монолитных стенах и перекрытиях по этажам? Раздели по
> маркам бетона и выгрузи в Excel.

**Проверить заполнение параметров**
> У каких элементов не заполнен код классификатора? Сгруппируй по
> категориям и типам.

**Найти несоответствия**
> Найди стены, у которых в имени типа «200 мм», а фактическая толщина
> другая.

**Сравнить версии**
> Что изменилось между 3-й и 4-й версиями модели АР? Сколько элементов
> добавлено, удалено и изменено, в каких категориях?

**Быстрая справка**
> Сколько в модели противопожарных дверей EI60 и на каких этажах?

**Спецификация**
> Выгрузи в Excel все окна: тип, размеры, этаж, количество.

**Посмотреть модель**
> Дай ссылку на модель, хочу посмотреть проблемные элементы.

Ссылка открывает модель во вьювере Tangl, если вы вошли в Tangl в
браузере. Выделение по ссылке не передаётся, поэтому Claude даёт ещё и
список ID элементов.

## Если что-то не работает

| Сообщение | Что сделать |
|---|---|
| Нет выхода в сеть к auth.tangl.cloud | Добавьте домены Tangl в настройках (шаг 2) |
| Нет данных для входа | Добавьте `tangl.env` в проект или приложите к чату |
| Неверный логин или пароль | Проверьте `TANGL_USERNAME` и `TANGL_PASSWORD` |
| Неверные Client ID / Secret | Проверьте данные API в личном кабинете Tangl |
| Модель не найдена | Проверьте, что у вашей учётной записи есть доступ к модели |

## Безопасность

- Данные для входа хранятся в вашем проекте Claude и во временной среде
  разговора. В репозиторий и третьим лицам они не передаются.
- Коннектор физически не отправляет в Tangl запросы на изменение: любой
  такой запрос блокируется до отправки.
- Не публикуйте `tangl.env` и не пересылайте его другим людям.

## Другие ИИ-ассистенты

Коннектор рассчитан на Claude. В обычном чате ChatGPT код не выходит в
интернет, поэтому подключиться к Tangl оттуда нельзя.
