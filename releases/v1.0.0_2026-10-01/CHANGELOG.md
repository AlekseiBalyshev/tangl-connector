# Изменения

## v1.0.0 · 2026-10-01

- Таблица `materials`: материал, объём и класс бетона из названия материала («Бетон В25 W6 F150» → В25). Вопрос «сколько бетона по этажам и по маркам» теперь работает.
- Признак `service` у служебных элементов (камеры, уровни, виды, листы); рецепты проверки параметров их исключают.
- В ответах `query` и `model_schema` есть `source`: модель, версия, дата. Claude подписывает источник под каждой таблицей.
- Проверка размера до выгрузки: версии больше 200 000 элементов не выгружаются, коннектор советует выбрать модель раздела. Порог – `TANGL_MAX_ELEMENTS`.
- `status` проверяет порт из адреса, а не всегда 443 (ложное «нет сети» на своём сервере Tangl).
- Инструмент `clean`: удаление выгруженных данных, с `--all` – и данных для входа.
- README: установка в 4 шага, ограничения, абзац на английском. USER_GUIDE: что и где хранится.
- Сравнение версий помечено как надёжное только для Revit.

## v0.1.0 · 2026-09-30

Первая тестовая версия.

- Инструменты `status`, `login`, `find_models`, `model_schema`, `query`, `model_link`.
- Вход по персональному токену Tangl (основной способ) либо клиентом API с логином и паролем.
- Поиск по всем компаниям пользователя, `TANGL_COMPANY_ID` необязателен.
- Сравнение двух версий модели в одном запросе (`query --compare`).
- Только чтение: запросы на изменение блокируются до отправки в Tangl.
